# KURIASPACE AI Literacy Bootcamp

Course website for a five-day AI literacy bootcamp for young people in Kenya, in or out of school.
No prior AI knowledge and no coding needed.

**Live site:** https://kuriaspace.github.io/ailiteracy/

## What's here

| Path | What it is |
|---|---|
| `index.html` | The course page: daily resources, readings, project rubric, glossary, feedback form |
| `slides/view/day1` … `day5` | Slide images shown in the page's view-only slide viewer |
| `data/matatu_delays_training.csv` | 200 matatu trips with the answer (`delayed`), for the Day 2 "Be the algorithm" activity |
| `data/matatu_delays_test.csv` | 40 new trips without the answer; students fill in `your_prediction` |

The matatu data is synthetic (made up for teaching), but the patterns are realistic.
